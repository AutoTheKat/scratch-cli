# Scratch-CLI
Run Scratch and TurboWarp projects directly in your terminal.

Submit issues or suggestions [here](https://github.com/LordCat0/scratch-cli/issues).


## Installation
`npm i -g @lordcat/scratch-cli`

## Usage Examples
- `scratch-cli ./project.sb3`
- `scratch-cli 463553665`
- `scratch-cli https://scratch.mit.edu/projects/463553665`
- `scratch-cli https://example.com/project.sb3`

You can also write `scr` instead of `scratch-cli`.

## Options
- `--vm=<path>` - Custom VM path
- `--renderer=<path>` - Custom Renderer path
- `--storage=<path>` - Custom Storage path
